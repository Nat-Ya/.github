## How we work

- **Lean · Shift-Left · Cloud-ready**: smallest useful increment, security and quality checked early, 12-factor by default.
- **TDD, Clean Code, SOLID**: tests first, small functions, intention-revealing names.
- **Decisions on record**: architecture decisions are written down as ADRs.
- **AI-assisted, human-governed**: automated agents work through labelled issues and pull requests. **Only a human merges.**

Our shared issue and pull request templates and Definition of Done live in [`.github`](https://github.com/Nat-Ya/.github).
